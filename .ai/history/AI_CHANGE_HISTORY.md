# AI Change History

> TEMPLATE — a running, dated log of significant AI-driven changes to
> this project, for traceability. Distinct from `../decisions/ARCHITECTURE_DECISIONS.md`
> (which records *why* a decision was made) and
> `../failures/LESSONS_LEARNED.md` (which records *problems solved*) —
> this file is the plain chronological record of *what happened, when*.

## How to add an entry

```markdown
## YYYY-MM-DD — [short title]

**What changed**: [one or two sentences.]
**Why**: [the real trigger — a request, a bug, a planned improvement.]
**Files/areas affected**: [real paths or module names.]
**Related**: [link to a decisions/ or failures/ entry, if applicable.]
```

## When to add an entry

Same criteria as `../MEMORY_UPDATE_RULES.md` — significant changes only,
not every commit. This log is meant to stay scannable, not become a
mirror of the full git history.
